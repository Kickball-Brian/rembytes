# rembytes.com

Vite + GSAP + Three.js + Lenis. Static output, host anywhere.

```
npm install
npm run dev       # http://localhost:5173
npm run build     # outputs ./dist — upload that folder to the web root
```

- Headshot: drop `public/brian.jpg` (replaces the BR monogram automatically).
- Copy lives in `index.html`; particle formations in `src/scene.js`; interactions in `src/main.js`.
- Placeholder content: the four "Case study" cards in the Work section, the LinkedIn URL.
- Press ⌘K / Ctrl+K (or `/`) for the command palette.
